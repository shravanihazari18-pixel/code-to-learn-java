Introduction to Java

Lesson 1 • Beginner

What is Java?

Java is a popular programming language used to build applications, websites, games, and many other software systems.

Java was designed to be simple, secure, and platform-independent.

Why Learn Java?

  • Easy to learn for beginners
  • Object-oriented programming language
  • Works on different operating systems
  • Used in Android and enterprise applications
  • Large developer community

Your First Java Program

Let's write a simple Java program that prints "Hello World". 

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Understanding the Program

public class Main creates a class called Main.

main() is the starting point of a Java program.

System.out.println() prints text on the screen.

Quick Check

  • A. start()
  • B. main()
