Classes & Objects

Learn how Java uses classes and objects to create real-world programs.

What is a Class?

A class is a blueprint or template used to create objects. It can contain variables and methods.

For example, a Student class can contain a student's name, age, and methods to display student information.

What is an Object?

An object is an instance of a class. We create objects using the new keyword. 

Student student1 = new Student();

Creating a Class

class Student {

    String name;
    int age;

    void display() {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

Creating an Object

public class Main {

    public static void main(String[] args) {

        Student student1 = new Student();

        student1.name = "Rahul";
        student1.age = 20;

        student1.display();
    }
}

Output:

Name: Rahul
Age: 20

Important Concepts

  • Class: Blueprint for objects.
  • Object: Instance of a class.
  • Variable: Stores data inside a class.
  • Method: Performs an action.
  • new: Creates an object.

Quick Check

Which keyword is commonly used to create an object in Java?

Answer: new
