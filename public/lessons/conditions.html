Conditional Statements

Learn how Java makes decisions using conditions.

What are Conditional Statements?

Conditional statements allow a Java program to make decisions. A block of code runs when a particular condition is true.

Java provides if, if-else, else-if, and switch statements.

1. if Statement

The if statement executes code only when its condition is true. 

int age = 20;

if (age >= 18) {
    System.out.println("You are an adult");
}

Output:

You are an adult

2. if-else Statement

The else block runs when the condition is false. 

int number = 7;

if (number % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}

Output:

Odd

3. else-if Statement

Use else-if when you need to check multiple conditions. 

int marks = 85;

if (marks >= 90) {
    System.out.println("Grade A+");
} else if (marks >= 75) {
    System.out.println("Grade A");
} else if (marks >= 60) {
    System.out.println("Grade B");
} else {
    System.out.println("Grade C");
}

Output:

Grade A

4. switch Statement

A switch statement is useful when you want to compare one value against multiple possible values. 

int day = 2;

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");
}

Output:

Tuesday

Important Operators

  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to
  • && Logical AND
  • || Logical OR
  • ! Logical NOT

Quick Check

Which statement is used when you want to execute one block when a condition is true and another block when it is false?

Answer: if-else
