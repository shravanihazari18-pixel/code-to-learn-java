Variables & Data Types

Lesson 2 • Beginner

What is a Variable?

A variable is a container used to store data in a Java program.

For example, we can store a student's age, name, marks, or any other value inside a variable.

Variable Syntax

A Java variable is normally declared using a data type, followed by the variable name and value. 

dataType variableName = value;

Example:

int age = 20;
String name = "Alex";
double marks = 85.5;

Java Data Types

  • int - stores whole numbers
  • double - stores decimal numbers
  • float - stores decimal numbers
  • char - stores one character
  • boolean - stores true or false
  • String - stores text

Java Example

Here is a simple program using different variables: 

public class Main {

    public static void main(String[] args) {

        String name = "Alex";

        int age = 20;

        double marks = 85.5;

        boolean passed = true;

        System.out.println("Name: " + name);

        System.out.println("Age: " + age);

        System.out.println("Marks: " + marks);

        System.out.println("Passed: " + passed);
    }
}

Important Points

  • Every variable has a data type.
  • Variable names should be meaningful.
  • Java is case-sensitive.
  • Variables can be changed during program execution.
  • Use String for storing text.

Quick Check

Which data type is used to store a whole number?

  • A. String
  • B. double
  • C. int
  • D. boolean

Answer: C. int
