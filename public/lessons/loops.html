Loops

Lesson 5 • Beginner

What is a Loop?

A loop repeats a block of code multiple times.

Types of Loops

  • for loop
  • while loop
  • do-while loop
  • Enhanced for loop

for Loop Example

public class Main {
    public static void main(String[] args) {

        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}

Quick Check

Which loop is commonly used when the number of repetitions is known?

  • A. for
  • B. if
  • C. switch
  • D. catch

Answer: A. for
